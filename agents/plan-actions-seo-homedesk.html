🔴 Priorité critique  À faire en premier

A0 — Diagnostiquer la découverte & l'effondrement du 2026-07-11 🟦 SEO/GSC

Problème : Google ne connaît que 4 URL sur ≈12 déclarées au sitemap, et le nombre d'URL connues est tombé de 14 → 3 le 2026-07-11. Tant que la cause n'est pas comprise, les autres actions risquent d'être annulées.

Pourquoi d'abord : c'est le diagnostic qui conditionne tout le reste (inutile de « demander l'indexation » si un événement structurel refait perdre les URL).

Étapes concrètes

  1. GSC → Sitemaps : vérifier que sitemap_index.xml est soumis, statut « Réussite », et noter le nombre d'URL découvertes. Re-soumettre si besoin.
  2. GSC → Inspection d'URL sur /produit/bureau-ergonomique/ et /boutique/ : l'URL est-elle « connue de Google » ? explorée ? Lancer « Tester l'URL en direct ».
  3. Reconstituer le changement du 11/07 : consulter le plugin Redirection (date des règles), l'historique des slugs, et la régénération du sitemap Yoast. Identifier ce qui a été modifié ce jour-là.
  4. Vérifier dans GSC → Paramètres → Statistiques d'exploration s'il y a eu un pic d'erreurs / de redirections autour de cette date.
Impact : Très élevé Effort : Faible (1–2 h) Responsable : SEO / GSC Dépendances : accès GSC

A1 — Forcer la découverte des pages clés 🟦 SEO/GSC

Problème : le produit, la boutique et les pages de contenu sont absents de la couverture Google (ni indexés, ni listés comme non-indexés).

Pourquoi : techniquement indexables mais jamais traités → il faut provoquer l'exploration.

Étapes concrètes

  1. GSC → Inspection d'URL → « Demander l'indexation » pour, dans l'ordre : /produit/bureau-ergonomique/, /boutique/, /notre-solution/, /notre-histoire/, /contactez-nous/.
  2. Vérifier que ces URL sont bien dans le sitemap Yoast (elles le sont) et que le sitemap est à jour (regénérer après les corrections A2–A6).
  3. Après 3–7 jours, re-contrôler le statut d'indexation dans GSC.
À faire après A2 (liens internes) idéalement, pour que Google découvre directement les bonnes URL et pas des redirections.
Impact : Élevé Effort : Faible Responsable : SEO / GSC

A2 — Corriger les liens internes qui pointent vers des redirections 🔧 Dev

Problème : plusieurs liens internes visent des URL qui répondent en 301 → Google « voit » surtout des redirections (cohérent avec les 3 « Page avec redirection »), au lieu des URL finales.

Pourquoi : corriger ces liens fait découvrir directement les bonnes pages — action à impact SEO immédiat et sous notre contrôle (code).

Emplacements confirmés dans le code

Lien actuelCible correcteFichier
home_url('/contact') → 301 /contactez-nous/ wp-content/themes/oceanwp/woocommerce/content-single-product-stacked.php (≈ ligne 160, bloc team-offer)
home_url('/contact') → 301 /contactez-nous/ wp-content/plugins/one-page-cod/includes/class-opc-form.php (bloc team-offer)
/produit/homedesk/ ×3 → 301 /produit/bureau-ergonomique/ 🧠 Page d'accueil — probablement dans Elementor (contenu en BDD). À corriger via l'éditeur Elementor (boutons/liens de l'accueil).

Étapes concrètes

  1. Code (2 fichiers ci-dessus) : remplacer home_url('/contact') par home_url('/contactez-nous/') (ou mieux, un lien dynamique — voir note).
  2. Accueil (Elementor) : ouvrir la page d'accueil dans Elementor, repérer les 3 boutons/liens vers l'ancien slug /produit/homedesk/ et les repointer vers /produit/bureau-ergonomique/.
  3. Vérifier aussi le menu (Apparence → Menus) et le footer : aucun lien vers /contact ou /produit/homedesk/.
  4. Ne pas supprimer les règles de redirection existantes : elles restent utiles comme filet de sécurité pour les liens externes/anciens.
  5. Vider le cache (LiteSpeed / WP Super Cache) après modification.
🔧 Note anti-régression : pour éviter que ça se reproduise, préférer des liens robustes au slug en dur — ex. get_permalink( wc_get_page_id('...') ) ou l'ID de la page contact, plutôt que home_url('/contact').
Impact : Élevé Effort : Faible–Moyen Responsable : Dev

🟠 Priorité importante  Hygiène d'indexation

A3 — noindex + exclusion du sitemap pour les pages « bruit » 🟦 SEO

Problème : /cart/ et /my-account/ sont indexables (index,follow), et /categorie/uncategorized/ + /?oceanwp_library=footer figurent dans les sitemaps.

Pourquoi : ces pages n'ont aucune valeur SEO et diluent le crawl / brouillent le signal. Les exclure explicitement concentre Google sur les pages utiles.

Étapes concrètes (Yoast SEO)

  1. cart / checkout / my-account : éditer chaque page → encart Yoast → onglet Avancé → « Autoriser les moteurs à afficher cette page ? » = Non (met en noindex + sort du sitemap).
  2. Type de contenu Ocean Library : Yoast → Réglages → Types de contenu → oceanwp_library → « Afficher dans les résultats de recherche ? » = Non.
  3. Catégorie « uncategorized » : voir A9 (renommer / réassigner). En attendant, la passer en noindex via Yoast sur la catégorie.
  4. Régénérer le sitemap (Yoast le fait automatiquement) et vérifier que ces URL en ont bien disparu.
Impact : Moyen Effort : Faible Responsable : SEO

A4 — Corriger les H1 🔧 Dev 🧠 Contenu

Problème : /boutique/ a 0 H1, /notre-histoire/ a 0 H1, /notre-solution/ a 2 H1.

Pourquoi : un H1 unique et descriptif est un signal on-page de base pour la pertinence.

Étapes concrètes

  • Boutique : ajouter un titre H1 (ex. « Nos bureaux ergonomiques »). Selon le rendu, via l'option de titre OceanWP de la page boutique ou un hook woocommerce_shop_loop / template.
  • Notre-histoire : ajouter un H1 en tête de page (Elementor : passer le titre principal en balise H1).
  • Notre-solution : garder un seul H1, rétrograder le second en H2.
Impact : Moyen Effort : Faible Responsable : Dev / Contenu

A5 — Ajouter les meta descriptions manquantes 🧠 Contenu

Problème : meta description absente sur /notre-histoire/ (et à vérifier sur les autres pages de contenu).

Pourquoi : améliore le taux de clic et la compréhension de la page.

Étapes concrètes

  • Éditer chaque page → encart Yoast → renseigner une meta description unique de 140–160 caractères avec le mot-clé principal.
Impact : Faible–Moyen Effort : Faible Responsable : Contenu

A6 — Renforcer le maillage interne 🧠 Contenu 🔧 Dev

Problème : pages sous-maillées / orphelines (/boutique/, /notre-histoire/) ; maillage global pauvre.

Pourquoi : le maillage transmet l'autorité et guide la découverte — directement lié au problème central.

Étapes concrètes

  • Ajouter depuis l'accueil et la page produit des liens contextuels vers boutique et notre-histoire.
  • Vérifier que le menu principal + footer couvrent les pages clés (produit, boutique, solution, histoire, contact).
  • Depuis la page produit, lier vers /notre-solution/ et /boutique/ (produits liés).
Impact : Moyen–Élevé Effort : Moyen Responsable : Contenu / Dev

🟡 Priorité mineure  Optimisations de fond

A7 — Traduire les pages / titres en anglais 🧠 Contenu

Problème : titres EN résiduels (« My Account », « Uncategorized Archives »). Site en français.

Étapes concrètes

  • Traduire le titre de /my-account/ (« Mon compte ») — de toute façon passée en noindex (A3).
  • Régler la catégorie « Uncategorized » (voir A9).
Impact : FaibleEffort : FaibleResponsable : Contenu

A8 — Consolider le robots.txt 🔧 Dev

Problème : deux blocs User-agent: * redondants (natif + bloc Yoast).

Étapes concrètes

  • Fusionner en un seul bloc propre (Yoast → Outils → Éditeur de fichiers, ou filtre robots_txt). Conserver le Disallow: /wp-admin/ (+ Allow: admin-ajax.php) et la ligne Sitemap:.
Impact : FaibleEffort : FaibleResponsable : Dev

A9 — Structurer les catégories produit 🧠 Contenu

Problème : catégorie « uncategorized » vide/faible valeur dans le sitemap.

Étapes concrètes

  • Créer une vraie catégorie produit (ex. « Bureaux ergonomiques ») et y assigner le produit.
  • Supprimer / vider « uncategorized » et la sortir du sitemap (noindex si conservée).
Impact : Faible–MoyenEffort : FaibleResponsable : Contenu

A10 — Créer du contenu éditorial (blog) 🧠 Contenu

Problème : aucun contenu de blog → faible surface d'indexation et faible autorité thématique.

Pourquoi : levier de fond pour dépasser le plafond « 1 page indexée » et capter des requêtes informationnelles.

Étapes concrètes

  • Publier des guides ciblés : ergonomie, mal de dos, bureau assis-debout, choix de la taille (S/M/L) — avec liens internes vers le produit et la boutique.
  • Travailler l'autorité en parallèle : Google Business Profile, backlinks, réseaux (levier n°1 pour un domaine récent).
Impact : Élevé (long terme)Effort : ÉlevéResponsable : Contenu
